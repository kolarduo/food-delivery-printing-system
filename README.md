# Rocket外卖打印工具

轻量级 Windows 桌面程序，用于读取、筛选、查看并打印 Rocket Now Manager 订单。当前版本为 `0.2.2`。

## 0.2.2 可以做什么

- 点击“刷新订单”后打开 Rocket Now Manager 官方页面读取订单。
- 未登录或登录过期时，可直接在官方页面完成登录。
- 使用 WebView2 保存 Rocket 登录会话，并支持 Edge 的密码保存和自动填充。
- 自动读取 Rocket Manager 默认查询范围内的订单，并继续翻页读取。
- 按日期优先读取：选择某一天时，只保留当天订单；读到更早日期的订单会停止，且不会把更早日期订单加入结果。
- 已读订单会缓存到本机；关闭软件再打开后仍可保留已读记录。
- 再次刷新时，如果读到当前日期里本机已经有的订单，会停止继续翻页并合并显示本地记录。
- 店铺筛选固定支持 7 家店铺和“全店铺”，默认选择“海底撈火鍋 川崎店”。
- 固定店铺包括：上野店、池袋店、新宿店、秋葉原店、難波店、横浜駅前店、川崎店。
- 显示订单号、下单时间、状态、主要商品和金额。
- 详情里显示商品、数量、价格和总价。
- 详情窗口可点击“打印”，打开 Windows 打印界面选择打印机或预览。
- 打印格式按 58mm 宽标签纸设计，高度随内容自动变化；商品和数量更醒目，价格字号较小。
- 以单个 Windows EXE 发布，无需解压其它文件。

## 使用方法

1. 运行 `Rocket外卖打印工具_v0.2.2.exe`。
2. 选择日期和店铺；默认店铺为川崎店。
3. 点击右上角“刷新订单”。
4. 如果未登录，请在 Rocket 官方页面登录。
5. 登录后或已经登录时，Rocket 窗口会在查询时最小化，主界面显示正在查询。
6. 读取完成后，可在软件内按日期和店铺筛选订单。
7. 点击订单“详情”，再点击“打印”预览或选择打印机。

## 当前限制

- 软件读取的是 Rocket Manager 页面默认查询范围内的数据；超出该范围的订单不会被读取。
- 当前版本支持手动打印单个订单，暂不支持自动打印或批量打印。
- 刷新时仍需要加载 Rocket Manager 页面；登录时会显示 Rocket 窗口，查询时会最小化。

## 技术方案

程序使用 Windows 原生 .NET Framework 和 Microsoft Edge WebView2，不捆绑 Electron、Chromium、Node.js 或 `node_modules`。

## 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

构建脚本会按需下载微软官方 WebView2 SDK，并生成：

```text
dist\Rocket外卖打印工具_v0.2.2.exe
```

## 数据安全

- 登录会话和订单缓存只保存在本机 WebView2 用户目录。
- Cookie、登录令牌、请求调试文件和订单数据不会提交到 GitHub。
- 请勿将包含 Cookie、`unify-token` 或其它登录令牌的 F12 请求信息公开分享。
